# 도메인 문서와 어긋난 곳

| | |
| --- | --- |
| 작성 | 2026-09-01 |
| 마지막 대조 | 2026-09-04 |
| 대조한 것 | 위키 도메인 모델링 · API 설계 · `docs/SPEC-S2.md` · 실제 프론트 코드 |
| 남은 것 | **없음** |

**다섯 다 닫혔다.** 이 문서는 기록으로 남긴다. 같은 것을 다시 파헤치지
않으려고 무엇이 어떻게 닫혔는지만 적어둔다.

새로 어긋난 곳이 생기면 여기 다시 쓴다. 문서가 둘이면 같은 사실이 두
곳에 적히고 한쪽만 고쳐지면 갈라진다.

---

## 닫힌 다섯

| # | 무엇이 갈라졌었나 | 어떻게 닫혔나 | 언제 |
| --- | --- | --- | --- |
| 1 | 모집글 취소가 프론트에만 상태로 있었다 | 상태에서 빼고 `closedReason` 의 세 번째 값으로 옮겼다. 도메인 6장의 `OPEN → CLOSED` 둘뿐인 전이도표와 맞고, 완료와 취소의 구분은 사유에 남는다 | 09-03 |
| 2 | 방장이 자기 글의 댓글을 못 지웠다 | `comment-perm.ts` 의 `actionsFor` 가 방장에게 `DELETE` 를 준다. 판정을 한 곳으로 모으면서 같이 닫혔다 (CM-18) | 09-03 |
| 3 | 비회원이 공개 댓글을 볼 수 있는지가 도메인 7.1 표 안에서 부딪혔다 | 위키가 「비회원 및 회원 전체」 로 고쳤다. 프론트는 원래 그렇게 동작하고 있었다 (CM-20) | 위키 |
| 4 | 만남 지점 이름이 `MeetPoint` 와 `MeetingPoint` 둘이었다 | 위키가 `MeetPoint` 로 통일했다. 1장 용어표와 프론트 코드가 원래 그쪽이었다 | 위키 |
| 5 | `deadlineAt < meetAt` 부등호가 성립할 수 없었다 | 위키 I-04 가 `meetAt ≤ 행사 종료시각` 만 남겼다. 마감 입력 칸이 없어서 `closesAt` 이 `meetAt` 과 같아지는 문제가 사라졌다 | 위키 |

**셋은 위키 쪽에서 닫혔다.** 이 문서를 올린 뒤에 도메인 모델링이
개정되면서 자연히 정리됐다. 우리가 따로 요청하지는 않았다.

## 09-04 에 다시 대조한 결과

계약 문서 넷과 프론트 코드를 전수로 맞춰봤고, 그때 나온 열넷은 별도로
처리했다. 그중 프론트가 고친 것은 아래와 같다.

| 무엇 | 어디 |
| --- | --- |
| `closedReason` 값 이름을 `MEET_TIME_PASSED` 로 | `types.ts` |
| 시각 포맷을 ISO-8601 + KST 오프셋으로 | `lib/when.ts` 신설 |
| 카카오 프로필 이미지를 처리방침에서 뺐다 | `privacy/page.tsx` |
| 최근 접속일을 구간값으로 넣고 동행 횟수를 뺐다 | `types.ts` · `ProfileView` |
| 댓글 액션을 서버가 정하게 했다 | `comment-perm.ts` |
| 만남 지점 핀을 필수로 | `types.ts` · `NewPost` |
| 댓글 수를 조회할 때 세게 | `p/[id]/page.tsx` |
| 상태 필드 이름을 `status` 로 | `types.ts` · `PostList` · `ProfileView` · `PostDetail` |
| 본문 필드 이름을 `content` 로 | `types.ts` · `comment-perm.ts` · `PostDetail` |
| 죽은 `doneCount` 를 `ListItem` 에서 제거 | `p/PostList.tsx` |


**09-04 오후에 셋이 더 나왔다.** 댓글 응답 JSON 예시를 필드 단위로는 안
봤던 탓이다. 위키가 `status` · `content` 로 일관되고 (API 설계 2-5,
API 컨벤션 공통 응답 형식) 모집글·댓글은 백엔드가 정본이라 프론트가
움직였다. 행사는 반대로 프론트가 정본이라
[행사 카탈로그 계약](../../duckmoim-wiki/02-설계-아키텍처/행사-카탈로그-계약.md)
으로 따로 뺐다.

**아직 백엔드와 말을 맞춰야 하는 것은 이 문서에 넣지 않는다.** 그건
갈라진 것이 아니라 아직 안 정한 것이라 성격이 다르다.
