# 덕모임 디자인 브리프

읽는 순서: 이 파일 → `photos.md`(목업용 실제 사진) → `src/app/globals.css`(현재 토큰)

---

## 1. 무엇인가

서울에서 오늘 열리는 **생일카페와 팝업**을 지도와 목록으로 모아 보여주는 모바일 웹.
`https://duckmoim.com` 에 이미 떠 있고 매일 자동으로 갱신된다.

지금 필요한 건 **첫 화면(홈)의 시각 시안**이다. 기능은 다 돌아간다. 문제는 보이는 것.

## 2. 누가 언제 쓰나

**혼자 덕질하러 나온 사람이, 길에서, 한 손으로.**

홍대입구역 9번 출구에서 나와 "지금 어디부터 가지"를 정하는 3분.
데스크톱에서 느긋하게 둘러보는 화면이 아니다. **375px 폭이 기본**이고
데스크톱은 그 다음이다.

경쟁 서비스가 이미 있고 우리보다 크다.
오프메이트(설치 10만+), 덕플레이스(평점 4.8). 그들이 못 하는 건
**생카와 팝업을 한 화면에** 놓는 것뿐이다. 그 외에는 다 밀린다.
그래서 첫인상에서 지면 끝난다.

## 3. 지금 화면

하단 탭 4개. 이번 작업 범위는 **홈 하나**다.

| 탭 | 답하는 질문 |
|---|---|
| **홈** | 오늘 뭐가 제일 크고, 내 동네엔 뭐가 있나 |
| 찾기 | 이름으로 검색 |
| 지도 | 어디 붙어 있나 |
| 내 코스 | 담아둔 것 |

홈의 현재 구성: 로고 헤더 → 순위 캐러셀 → 필터 바 → 지역별 2열 그리드.
이 뼈대는 유지해도 되고 갈아엎어도 된다. **판단 근거는 아래 4번이다.**

## 4. 실제 콘텐츠의 모양 (이게 디자인을 결정한다)

지어낸 데이터로 예쁘게 나오는 시안은 실물에서 무너진다. 진짜 숫자는 이렇다.

| 사실 | 값 | 디자인에 주는 제약 |
|---|---|---|
| 진행 중 | **191건** | 한 화면에 다 못 넣는다. 무엇을 먼저 보일지가 전부 |
| 지역 쏠림 | 홍대 **134**, 용산 21, 합정 15, 나머지 21 | 지역별로 나누면 **홍대 하나가 70%**다. 균등한 그리드는 거짓말이 된다 |
| 유형 쏠림 | 생카 **172** vs 팝업 **19** | "생카/팝업" 토글은 한쪽이 거의 비어 있다 |
| 운영시간 | **191건 중 20건만** 있음 | 카드에 "10:00~18:00"이 대부분 없다. 날짜 범위로 떨어진다 |
| 굿즈 있는 팝업 | **0건** | 홈의 "팝업 굿즈" 섹션은 지금 아무것도 안 뜬다 |
| 최다 대상 | 성호 29곳, 정국 22, 장원영 13, 필릭스 11 | **순위를 세울 만큼 격차가 있다.** 지금 홈의 캐러셀이 이걸 쓴다 |
| 긴 문자열 | `롯데백화점 잠실점 2층 키네틱 스테이지` | 한 줄에 안 들어간다. 두 줄 처리 또는 말줄임이 필요 |

전부 **한국어**다. `word-break: keep-all` 이 걸려 있어 어절 단위로 꺾인다.
영문 목업으로 만들면 줄바꿈이 전혀 다르게 나온다. **한국어로 만들 것.**

## 5. 이미 정해진 것

`src/app/globals.css` 의 `:root` 가 현재 토큰이다.

**유지**
- 라이트 전용. 다크 모드 없음 (커뮤니티 스크린샷과 톤을 통제하기 위함)
- accent 는 핑크 계열 `#ff4d8d`. 핑크 배경 위 글자는 `--accent-ink`
- 좌우 시작선은 `--gutter` 하나로
- 입력 필드 16px 미만 금지 (iOS 확대 유발)
- 품절은 빨강이 아니라 회색 + 취소선

**바꿔도 되는 것**
- 타이포 스케일, 여백 리듬, 카드 구조, 섹션 구성, 사진 쓰는 법, 장식 요소
- accent 의 채도와 명도 (계열만 유지)

**로고**는 아직 없다. 헤더 왼쪽에 글자 `덕모임` 이 임시로 들어가 있고,
`public/logo.svg` 를 넣으면 그림으로 바뀐다. 시안에서는 **로고 자리(높이 30px)만 잡아두면** 된다.

## 6. 하지 말 것

지금까지 시안이 실패한 방식들이다. 그대로 반복하지 마라.

- **회색 네모와 글자만 있는 화면.** `photos.md` 에 진짜 사진 6장을 data URI 로 넣어뒀다.
  아티팩트가 외부 이미지를 못 불러오는 것이지 사진이 없는 게 아니다. **반드시 쓸 것**
- **보라·인디고 그라디언트.** AI 가 뽑은 티가 가장 크게 나는 색이다
- **Inter / Geist.** 한국어 사이트다. 시스템 한글 스택을 쓴다
- 전부 가운데 정렬
- 섹션마다 붙는 작은 대문자 라벨(eyebrow)
- 이모지 아이콘으로 때우는 것
- 실제로 없는 데이터로 채운 화면 (평점, 리뷰 수, 좋아요 수, 방문자 수는 **없다**)

## 7. 이번에 원하는 것

**홈 한 화면을, 375px 폭으로, 실물 데이터와 실물 사진으로.**

여러 시안을 얕게 뽑는 것보다 **한 화면을 끝까지** 밀어붙인 것이 낫다.
아래가 다 들어가야 한다.

1. 헤더 (로고 자리 + 검색 진입)
2. 오늘 가장 큰 것을 보여주는 영역 (지금은 성호 29곳 / 정국 22곳 / 장원영 13곳 순위)
3. 필터 (날짜 · 지역 · 유형)
4. 카드 목록 (홍대가 134건이라는 현실을 반영해서)
5. 하단 탭 4개

## 8. 완성 기준

- 375px 에서 가로 스크롤이 생기지 않는다
- 사진이 실제로 들어가 있다 (`photos.md`)
- 홍대 134건 / 나머지 57건이라는 쏠림이 화면에서 자연스럽다
- 운영시간이 없는 카드가 어색하지 않다 (191건 중 171건이 그렇다)
- 스크린샷을 커뮤니티에 올렸을 때 "이거 뭐야" 소리가 나온다
