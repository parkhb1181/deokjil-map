# 소개 사이트 사진

출처는 Unsplash 다. 상업적 이용이 허용되고 출처 표기 의무는 없다.
파일명으로 확인된 촬영자: polina-kuzovkova, yeon-lee, joel-muniz.
나머지는 번들에서 촬영자 정보가 떨어져 나와 확인하지 못했다.

## 쓰지 않기로 한 것

받아온 일곱 장 중 둘은 뺐다.

- 굿즈 매대 (아이돌 포스터와 티셔츠가 크게 나옴)
- 옥외 전광판 (아이돌 얼굴이 보임)

사진 자체는 자유롭게 쓸 수 있어도, 우리 서비스 홍보물에 특정 아이돌의
이미지와 소속사 상표가 실리는 건 다른 문제다. 얼굴이 식별되지 않는
것만 골랐다.
